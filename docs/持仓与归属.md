## 二、真正的约束不是“锁不锁”，是“卖不卖得动”

池子 USDT 侧只有 **8.079136 美元**。按现价 2.87 亿枚名义价值 $227.8，但只要真的卖出 1%（2,870,000 枚），池子会被击穿，价格趋近于零。

结论：**这批持仓的经济意义是治理与划转凭证，不是变现能力。** 对外写“储备用途与划转规则”，不写“锁仓”。

## 四、划转规则（已定）

1. **月度上限 2%**：每月从 operatorCenter 转出不超过 5,740,000 枚（287,000,000 × 2%）。
2. **逐笔公开**：每笔划转在仓库 `docs/划转记录.md` 与 X 同日登记，记 tx hash、数量、用途、接收地址。不接受只发月度汇总。
3. **暂停条件**：池子 USDT 侧低于 5 美元时当月不划转——划转即可能被读成砸盘信号。
4. **不卖给市场**：划转只发生在自有地址之间；operatorCenter 不直接向 PancakeSwap 卖出。如未来确需流动性，走“加池”而不是“卖出”。
5. **可核验**：任何时点 `balanceOf(0x8e49…)` 与 `docs/划转记录.md` 累计数应能对上。
